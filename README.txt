NEDUKA TASK – Paket GitHub Pages v1.3.2

Upload seluruh isi paket ini ke root repositori GitHub NEDUKA-TASK dan timpa file yang bernama sama. Jangan unggah folder pembungkusnya.

Pembaruan: memasang logo resmi SMP Negeri 2 Kawali pada identitas portal, menyempurnakan tampilan halaman autentikasi untuk laptop dan HP, memperhalus kartu/formulir, serta memperbarui cache agar desain baru dimuat.

Backend Google Apps Script tetap v1.3.0. Tidak perlu mengganti Code.gs, mengubah deployment, atau menjalankan setupNedukaTask(). Database tetap digunakan.

Setelah commit, buka https://indracandra.github.io/NEDUKA-TASK/ lalu tekan Ctrl+Shift+R. Pada HP, tutup tab lama lalu buka kembali alamat portal.
